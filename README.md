## 概日リズム睡眠ウィンドウ最適化

90分睡眠サイクルに基づく最適就寝時刻を計算し、睡眠慣性を最小化する「起きやすい時刻」を提示する睡眠改善ツール。

### 機能
- 起床希望時刻の入力（time input）
- 睡眠サイクル数スライダー（4・5・6サイクル）で推奨就寝時刻カード表示
- 現在時刻を入力すると「今から寝ると何サイクル？」を即時計算
- Canvas による睡眠段階タイムライン（深睡眠・浅睡眠・REM 色分け）
- localStorage による設定の自動保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas API（睡眠ステージタイムライン描画）
- localStorage（設定保存）
